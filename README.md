# pairwise-river-water

河水拐弯处流速突然反向、岸边泡沫穿模、物体落水不浮：流速按直线路径；河宽用固定值；泡沫用世界坐标噪声；浮力只按物体中心；水面折射抓屏没剔除水下；流向和法线贴图不同步；浅水深度用常数；河岸边缘没做混合；水面 LOD 接缝；多河段拼接流量不守恒。render/water_river.py 是核心，tests/test_water_river.py 15个红。要修的是：沿曲线流速；变宽度；随流泡沫；多点浮力；水下剔除；流向切线；深度采样；岸线混合；LOD 缝合；流量守恒。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
